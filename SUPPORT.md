# Getting help

CurioMap is a community project maintained in people's spare time, so the best way to get a quick answer is to
pick the right place to ask.

| I want to... | Go here |
|---|---|
| Set the project up locally | [Local development guide](docs/development.md), including [troubleshooting](docs/development.md#troubleshooting) |
| Ask a question or share an idea | [Discussions](https://github.com/curiomap/curiomap/discussions) |
| Report a bug | [Issues](https://github.com/curiomap/curiomap/issues/new/choose) (use the bug template) |
| Suggest a feature | [Issues](https://github.com/curiomap/curiomap/issues/new/choose) (use the feature template) |
| Contribute code or docs | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Report a **security** problem | [SECURITY.md](SECURITY.md). Please do not use a public issue. |
| Report a conduct problem | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Run my own instance | [Deployment guide](docs/deployment.md) |

## Before you ask

1. Search existing [issues](https://github.com/curiomap/curiomap/issues?q=is%3Aissue) and
   [discussions](https://github.com/curiomap/curiomap/discussions); someone may have solved it already.
2. Include your OS, how you run CurioMap (`npm run dev`, Docker, hosted) and the first error you see.
3. **Redact anything personal** (emails, tokens, locations) from logs and screenshots.

This project does not offer private or paid support, and maintainers cannot help with problems on a user's
own account on a hosted instance beyond what the privacy policy provides.
